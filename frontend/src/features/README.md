# features/

Один модуль = одна фіча продукту. Структура модуля:

```
features/<name>/
  api.ts          # запити до бекенду + react-query хуки
  types.ts        # типи відповіді API (дзеркало Pydantic-схем)
  components/     # компоненти фічі
  index.ts        # публічний експорт — інші модулі імпортують ТІЛЬКИ звідси
```

Планові модулі: `studies` (список/сторінка/порівняння тестів FLEX, графіки, replay), `agent` (чат, керування видом).
Спільне без бізнес-логіки → `shared/` (`api/` клієнт, `ui/` примітиви, `lib/` утиліти).
