# Прототип: 3D-відтворення ходу експерименту FLEX

> Робоча версія тепер у `frontend/src/features/experiment-3d` (вкладка «3D replay» на сторінці тесту, [ADR 0007](../../docs/decisions/0007-3d-replay.md)). Ця тека лишається як окремий застосунок для експериментів і далі не синхронізується.

Окремий Vite-застосунок, щоб перевірити ідею до інтеграції в `frontend/`. Показує тест у 3D за даними
(крапля, оболонки полум'я, слід дрейфу), графік d²(t) зі шкалою часу і справжні кадри з борту, синхронно.

## Запуск
```bash
# бекенд (з backend/), будь-який порт
uv run uvicorn flame.main:app --port 8000
# прототип (звідси)
npm install
npm run dev            # :5174, /api проксюється на :8000 (або VITE_PROXY_TARGET)
```
`http://localhost:5174/?test=146` — інший тест (типово 100).

## Звідки дані
Усе з наявного API, нічого не зашито в код:
- `/api/studies/flex/tests/{n}` — умови тесту, список файлів;
- `/api/studies/flex/tests/{n}/timeseries/{droplet|flame_uv|flame_color}` — розміри й положення;
- `/api/media/flex/{n}/cameras/{cam}/frames…` — кадри камер D (колір) і B (UV);
- журнал тесту `<CIR>.txt` (через `/api/media/flex/files/…`) — нуль часу.

**Нуль часу.** `t_s` у `ts_*` відлічується від рядка `AS Igniter Off/Retract Start` журналу. Час кадру:
`start_time + t_ms − igniter_off`. Перевірено на FLEX-100: UV-полум'я зникає з кадрів на 6.1–6.3 с,
у таблиці burn time 6.1 с. Зараз це рахує клієнт (`lib/experiment.ts`); при інтеграції краще віддавати
`t_s` кадрів з бекенду.

## Що з даних, а що художнє
- З даних: діаметр краплі, діаметри полум'я (UV і кольорова камера), положення краплі, усі моменти часу.
- Оцінка: 3D-положення зібране з двох проєкцій (x, y з HiBMS; z з UV-камери); полум'я центроване на краплі.
- З журналу тесту `<CIR>.txt`: моменти відведення голок, увімкнення й вимкнення запалювачів, кінець їх відведення.
- За документами NASA, у масштабі: камера згоряння CIR — циліндр із куполоподібними торцями, внутрішній
  діаметр 0.40 м, довжина 0.78 м, об'єм 100 л, вісім змінних вікон (NASA/TM—2005-213973, «The Fluids and
  Combustion Facility: Enabling the Exploration of Space», https://ntrs.nasa.gov/citations/20060003630).
  Цього документа немає у знімку PSI. Умовні: глибина куполів, розмір і розташування вікон, положення краплі
  в центрі камери, орієнтація осі камери відносно осей даних.
- Відстань кільця запалювача до краплі: один початковий діаметр (вимога 1–5 d₀, FLEX Engineering
  Requirements Document, п. 4.1.29; на кадрах — близько одного).
- Схема: форми голок і запалювачів (`components/Apparatus.tsx`). Зроблено за описом у
  документах FLEX (дві зустрічні голки з трубки 0.010″; два запалювачі з кільцем розжареного дроту; нитка SiC
  80 мкм — джерела в коментарі файлу) і за реальними кадрами кольорової камери. Розміри корпусів, відстані
  й тривалість відведення голок умовні.
- Оцінка: напрямок нитки в тестах з ниткою береться з напрямку зміщення краплі (вона ковзає вздовж нитки).
- Художнє: кольори оболонок, мерехтіння, відблиски, плавна поява і зникнення (0.25–0.3 с).
- Після кінця даних про полум'я нічого не домальовується (холодне полум'я — лише в коментарі дослідника).
