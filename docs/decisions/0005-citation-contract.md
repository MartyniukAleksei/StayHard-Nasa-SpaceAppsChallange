# 0005 — Контракт джерел: кожна відповідь агента має посилання

**Контекст.** Вимога продукту: агент **завжди** повертає посилання на джерело, з якого взяв інформацію. Інструкція в промпті цього не гарантує: модель може написати речення без цитати або вигадати посилання. Числа беруться з SQL-інструментів, тексти — з RAG, тож обидва шляхи мають давати посилання однаково.

**Рішення.**
1. **Будь-який результат інструмента агента — список `Source(url, title, text)`** (`flame/core/citations.py`). Його повертають `rag.service.search` (`Hit.to_source()`) і всі функції `studies/flex/service.py` (поле `sources`). `text` — те, що модель може процитувати: рядок таблиці словами (усі числа як у БД), коментар TestSheet, сторінка PDF, зведення часового ряду.
2. **`url` будуються лише функціями `citations.py`:**
   | Джерело | URL |
   |---|---|
   | рядок таблиці тесту | `/api/studies/flex/tests/{n}` |
   | часовий ряд | `/api/studies/flex/tests/{n}/timeseries/{signal}` |
   | файл знімка (TestSheet, txt, PDF, mp4) | `/api/media/flex/{path}`, для PDF `#page=N` |
   | опис дослідження, публікація | `https://doi.org/{doi}` |
   Відносні `/api/…` фронт розв'язує через `VITE_API_URL`; фронт може переписати `/api/studies/flex/tests/{n}` на свою сторінку тесту.
3. **Агент передає `Source` у Claude API як блоки `search_result` з `citations.enabled = true`** (`to_search_result`). API сам повертає в текстових блоках відповіді цитати `search_result_location` з `source` = наш `url`, `title` і дослівним `cited_text`. Модель не пише посилань сама, тож вигадати їх не може: кожна цитата вказує на результат інструмента в цьому запиті.
4. **Перевірка на сервері (етап агента):** текстовий блок відповіді, що містить число або фактичне твердження без жодної цитати, — перезапит або позначка «без джерела» в UI. Без результатів інструментів агент каже, що даних немає.
5. Відповідь агента — звичайний текст; цитати несумісні з `output_config.format`, тож керування UI (`open_view`) — окремим інструментом.

**Наслідки.**
- (+) Посилання гарантовано справжні й клікабельні; `cited_text` дозволяє перевірити твердження.
- (+) Новий інструмент/дослідження підключається, повернувши `sources`.
- (−) Сполучні речення без цитат можливі; що цитата справді підтверджує висновок — не гарантовано, лише перевіряється eval-ом агента.
- Залежимо від можливості `search_result` у Claude API (підтримують поточні моделі Claude; див. docs.claude.com → Search results).
