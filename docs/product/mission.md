# Mission — Flame in Freefall

> NASA Space Apps Challenge 2026 · челендж **Flame in Freefall: SI-Powered Fire Safety Insights from Microgravity Combustion Data**
> Фокус-дослідження: **FLEX — Flame Extinguishment Experiment (PSI-69)**, МКС, 2009–2012

## 1. Місія одним реченням

Агентний веб-інструмент, який за запитом природною мовою знаходить реальні тести FLEX, ставить їх поруч, «програє» кожен тест з польотних даних і пояснює, що відмінності між ними означають для пожежної безпеки екіпажу — від МКС до Місячної бази.

## 2. Навіщо (проблема)

- NASA десятиліттями збирає дані про горіння в мікрогравітації, але в PSI вони розкидані: таблиці, сотні тисяч сирих файлів, PDF-звіти. Знайти, порівняти й інтерпретувати їх важко (це прямо сказано в умові).
- Місячна база і ровери працюватимуть при **≥30% O₂ і ≤10.2 psi (~0.7 атм)** — значно більш пожежонебезпечна атмосфера, ніж на Землі.
- **FLEX уже містить тести саме в цих умовах**, але ця інформація прихована в рядках таблиці й сирих файлах.

## 3. Цільова аудиторія

| Хто | Що хоче | Що ми даємо |
|---|---|---|
| Аерокосмічний інженер (fire safety) | «Чи загасне полум'я при 34% O₂, 0.7 атм? Що спрацює — CO₂ чи He?» | Знайдені тести + висновок для безпеки + посилання на джерела |
| Дослідник / моделювальник | Дані для валідації моделі горіння краплі | Фільтри, часові ряди, експорт CSV, DOI |
| Студент | Зрозуміти, як горить крапля в невагомості | Replay тесту, пояснення простою мовою |

## 4. Чому FLEX

- **Пряма тема безпеки — гасіння:** атмосферу розбавляли CO₂ і He (кандидати для систем пожежогасіння) і шукали, коли полум'я гасне.
- **274 тести** в одній таблиці, однакова схема, 2 палива (метанол 157, гептан 117).
- **Широкий діапазон умов:** O₂ 0.12–0.34, тиск ≈0.7 / 1 / 2–3 атм, CO₂ 0–0.7, He 0–0.45, діаметр краплі 1.1–4.7 мм.
- **Багаті, але легкі дані на кожен тест:** часові ряди діаметра краплі і полум'я (кілобайти), Summary.pdf з графіками, відео mp4 (кілька МБ).
- **Місячний кейс уже в даних:** 17 тестів при ~0.7 атм і 30–34% O₂ (8 гептан, 9 метанол; фільтр `p_atm < 0.85 AND x_o2 >= 0.30`). Жоден не завершився самозгасанням: 15 Disruption, 2 Completion. Усі з N₂ як розбавником; тестів «≥30% O₂ + CO₂/He» немає. У повітрі при 1 атм більшість тестів закінчуються Extinction.
- Пов'язані дослідження для розширення: FLEX-2 (PSI-68), CFI (PSI-39), наземні моделі на даних FLEX (PSI-117, PSI-142).

## 5. Фізика FLEX (мінімум для команди)

- Крапля палива (1–5 мм) вільно плаває або тримається на тонкій нитці в камері CIR/MDCA на МКС. Її запалюють.
- Без підйомної сили полум'я — **сфера навколо краплі**. Кисень підходить тільки дифузією.
- Крапля зменшується за **законом d²**: $d^2(t) = d_0^2 - K t$, де $K$ — константа швидкості горіння (мм²/с, у таблиці колонка «Burning rate»).
- **Як закінчується тест (колонка `Test end`):**
  - **Extinction** — полум'я згасло, коли крапля ще не догоріла. Діаметр краплі в момент згасання записаний як `Visible flame extinction diameter`. Для безпеки це **добре**: атмосфера сама гасить вогонь.
  - **Completion** — крапля вигоріла повністю. Атмосфера гасіння не забезпечує.
  - **Disruption** — крапля розірвалась або дрейфувала (бульбашки, мікровибухи). Тест обірвано.
- **Cool flames** (відкриття FLEX): у гептану після згасання видимого полум'я реакція триває при ~600–800 K. Тобто «згасло» ≠ «безпечно».
- CO₂ і He гасять по-різному. CO₂ сильно поглинає тепло й випромінює. He має високу теплопровідність і швидко відводить тепло з полум'я.

## 6. Продукт: користувацький флоу

```
[1] Запит агенту ─► [2] Порівняння N тестів (вкладки/колонки) ─► [3] Сторінка одного тесту
        ▲                          │  агент доступний                   │  агент доступний
        └──────────── уточнення / «додай ще тест» / «знайди схожі» ─────┘
```

### [1] Пошук через агента
Приклад запиту: *«Знайди тести гептану при 0.7 атм і O₂ ≥ 30% і порівняй з тим самим паливом у повітрі»*.
Агент перетворює запит у фільтри → повертає 2–4 ID тестів з коротким поясненням, чому саме вони → відкриває екран порівняння.

### [2] Екран порівняння — картка кожного тесту
1. **Viewport** (див. §7) — replay тесту.
2. **Параметри:** паливо, тиск, O₂/N₂/CO₂/He, d₀, K, час горіння, діаметр згасання, тип завершення. Відмінності від інших тестів підсвічені.
3. **«Чим відрізняється»:** різниця параметрів, порахована детерміновано (diff), + пояснення від LLM з посиланнями.
4. **Графіки:**
   - d²(t) усіх обраних тестів на одному графіку (нахил = K);
   - діаметр полум'я та standoff ratio (діаметр полум'я / діаметр краплі) від часу;
   - **контекстний scatter усіх 274 тестів** (O₂ × розбавник, колір = Test end), обрані тести виділені.
5. **«Що це означає для безпеки»:** 2–3 речення, прив'язані до середовищ (МКС / Місячна база / ровер).
6. **Матеріали:** відео, Summary.pdf, TestSheet, посилання на PSI і DOI публікацій.

### [3] Сторінка тесту
Те саме, але детальніше: усі часові ряди, коментар дослідника з TestSheet, сусідні тести (найближчі за умовами), документи, експорт CSV. Чат з агентом у контексті цього тесту.

## 7. Viewport: принцип «тільки реальні дані»

| Режим | Що показує | Джерело |
|---|---|---|
| **Replay (MVP)** | Анімована схема: крапля + сфера полум'я в масштабі, таймлайн; курсор синхронізований з графіками | `DropletData.txt` (d(t), ~30 Гц), `ColorCamData.txt` / `LLUVData.txt` (діаметр полум'я, standoff) |
| **Відео (MVP)** | Запис з борту поруч зі схемою | mp4 з Raw Data |
| **What-if (stretch)** | Користувач змінює d₀ / O₂ / розбавник → **оцінка** K і часу горіння | Закон d² + інтерполяція між найближчими реальними тестами. Завжди з позначкою «оцінка» і списком тестів, з яких вона виведена |

Ми **не робимо CFD** і не вигадуємо фізику. Кожна цифра на екрані або виміряна, або виведена з названих тестів.

## 8. Дані

### Що є на кожен тест (папка Raw Data у PSI)
| Файл | Зміст | Використання |
|---|---|---|
| `FLEX-XXX_TestSheet.txt` | тиск, O₂/N₂/CO₂/He, T, паливо, D0, K, Dext, нитка (так/ні), **коментар дослідника** | параметри, текст для RAG |
| `FLEX-XXX_DropletData.txt` | час, діаметр краплі, позиція X/Y | replay, графік d²(t) |
| `FLEX-XXX_ColorCamData.txt` | час, діаметр полум'я, standoff (кольорова камера) | replay, графіки |
| `FLEX-XXX_LLUVData.txt` | діаметр полум'я, standoff з UV-камери (видно OH*) + позиція краплі | графіки |
| `FLEX_XXX_Summary.pdf`, `DropHist`, `Radiometer`, `Pressure_Temperature`, `BacklitSample` (pdf) | готові графіки від NASA | матеріали картки |
| `*_Chamber_Readings.txt`, `*_Radiometer_Readings.txt` | телеметрія камери, радіометр | графіки (stretch) |
| mp4 / zip з кадрами | відео | viewport |

Обсяг у PSI: 6 555 файлів, ~924 ГБ (основне — zip-и кадрів). **Нам потрібні лише txt/pdf/mp4**, тобто десятки МБ на тест.

### Пайплайн
1. `catalog_all_files.csv` → для кожного з 274 тестів знайти його файли. Зв'язок через `FLEX-XXX` / CIR-ідентифікатор (`20CAL10`, `192F001`).
2. Скачати txt + Summary.pdf для всіх тестів, mp4 — лише для показових (`backend/src/flame/ingest/psi_flex.py`).
3. Нормалізувати → `data/flex_tests.parquet` (1 рядок = тест) + `data/timeseries/{test}.parquet`.
4. Тексти (TestSheet comments, ABOUT, звіти, анотації публікацій за DOI) → чанки → векторний індекс.
5. Чистка даних: символ `–` (`\x96`) = пропуск; тиск у mmHg → атм; `Burning rate` = K у мм²/с.

## 9. Архітектура

```
Frontend (React/Next + Plotly/ECharts + Canvas/Three.js для viewport)
   │
Backend API (FastAPI)
   ├─ /tests?filters        → DuckDB/pandas по flex_tests
   ├─ /tests/{id}           → параметри, часові ряди, медіа
   ├─ /tests/{id}/neighbors → найближчі за умовами
   ├─ /media/{id}           → проксі до PSI (підписані S3-посилання), кеш
   └─ /agent (stream)       → LLM-агент
           ├─ query_tests(filters)       — структурований пошук
           ├─ compare_tests(ids)         — детермінований diff + статистика
           ├─ search_docs(query)         — RAG по звітах / TestSheet / публікаціях
           ├─ get_timeseries(id, signal)
           └─ open_view(ids)             — керує UI (відкриває вкладки)
```

**Правила агента:** відповідає лише з даних інструментів; кожне твердження має посилання (тест, файл, сторінка або DOI); якщо даних немає — так і каже; числа бере з інструментів, не генерує.

## 10. Обсяг робіт

- [ ] Цитування джерел у відповідях агента

### Stretch
- [ ] What-if-режим (оцінка K / burn time)
- [ ] Часові ряди для всіх 274 тестів

## 12. Демо-сценарій (2–3 хв)

1. Контекст: Apollo 1 → Місячна база буде при 30%+ O₂ і 0.7 атм.
2. Запит: *«Як горить гептан в атмосфері Місячної бази порівняно з повітрям МКС?»* → агент відкриває 3 тести.
3. Replay поруч: у повітрі полум'я гасне, при 34% O₂ / 0.7 атм — горить до розриву краплі.
4. Scatter: «місячні» тести — в зоні без самозгасання.
5. Запит: *«Що допоможе загасити? Порівняй CO₂ і He»* → агент знаходить тести з розбавниками, показує межі згасання.
6. Висновок для безпеки + посилання на тести і DOI. Застосування на Землі.

## 14. Відкриті питання та ризики

- Зв'язок «рядок таблиці ↔ папка сирих даних» перевірити для всіх тестів (є дублікат ID `193F001`, частина тестів без d₀).
- ~~Чи є mp4 для «місячних» тестів~~ — перевірено: **немає** (mp4 лише для 14 тестів, жоден не «місячний»). Replay у демо будуємо з часових рядів: `ts_droplet` є для 16 з 17 «місячних» тестів, діаметр полум'я — для всіх 17.
- Як позначено тести з ниткою (у TestSheet є `Fiber`). Їх не можна змішувати з вільними краплями.
- Disruption ≠ «горіло б вічно». Формулювати обережно: «самозгасання не спостерігалось».
- Ліміти/CORS PSI API → кешувати все потрібне до демо.
- Цитувати DOI FLEX і публікації (вимога PSI, ліцензія CC0).
