## StayHard: що обов'язково

**Токени** (`:root`, тема тільки темна):

| Токен | Значення | Роль |
|---|---|---|
| `--void` | `#050505` | фон, 60–90% площі |
| `--deep` | `#0e0e0d` | поля, код, поверхні |
| `--line` | `#262624` | рамки 1 px, роздільники |
| `--ash` | `#8d8d88` | підписи, другорядне |
| `--ink` | `#f1f0ea` | текст, форма, головна дія |
| `--flame` | `#4d6bff` | **лише** активне й «живе» (головна серія, активний тег) |
| `--paper` / `--soot` | `#ebe5d5` / `#151412` | інверсний набір для друку й постерів |
| `--end-ext` | `#6fa384` | фінал **Extinction** (приглушений зелений, контраст 7.0:1 на `--void`) |
| `--end-com` | `#c8735f` | фінал **Completion** (приглушений червоний, 5.9:1) |
| `--end-dis` | `#c09a52` | фінал **Disruption** (приглушена охра, 7.8:1) |

Кольори фіналів — розширення DS (рішення 2026-11-15). Відтінки ті самі, що в каркасах, але приглушені під чорне поле. Вживаємо їх **лише** для крапок на мапі, тексту чи мітки фіналу і тонких ліній. Заливки, фони й великі блоки цими кольорами не робимо. Колір завжди дублюється значком або текстом (`● Extinction`, `○ Completion`, `◇ Disruption`), бо зелений і червоний погано розрізняють люди з дальтонізмом. Синій `--flame` для фіналів не використовуємо.

**Шрифти** (кандидат за замовчуванням `dos`): назва й заголовки — `IBM VGA` 8×16 (вбудований woff у `stayhard-ds.html`, ліцензія CC BY-SA 4.0, автор VileR — атрибуція обов'язкова у футері); текст — `Geist`; цифри й гліфи — `Geist Mono` (Google Fonts). Масштаби: `--bz: .92` для назви, `--dz: 1.1` для заголовків.

**Компоненти:** кути прямі, тіней немає. Кнопка — моноширинний текст у дужках `[ Дія ]`, головна дія одна на екран і біла, другорядна — `--ash`. Тег — пунктирна рамка, активний — суцільна `--flame` + квадратна мітка. Показник — великі тонкі цифри (weight 300) + підпис `--ash`. Графік: виміри — растрові крапки, модель — тонка лінія, подія — синя мітка, назви серій — у легенді під графіком (див. «Графіки: одна тема»). Цілі кліку ≥ 44 px, фокус — `1px dashed var(--ink)`.

**Фактури:** будь-яке зображення рендеримо з яскравості `f(x, y, t)` у canvas однією з фактур (ASCII-рампа `" .:-=+*#%@"`, крапки та ін., клітинка 9 px). Еталон — функції `lum()` і `render()` у скрипті `stayhard-ds.html`. Анімації ≈11 кадрів/с, зупиняються поза екраном і при `prefers-reduced-motion`.

**Робимо:** чорне поле ≥ 60% кадру · одне велике зображення-фактура на екран · числа з одиницями (мм, с, мм²/с).
**Не робимо:** градієнти, неон, тіні, заокруглення · сирі фото без фактури · текст поверх найяскравішої частини зображення · синій як фон або великий блок.

**Виняток: 3D replay** (рішення 2026-11-15, [ADR 0007](../decisions/0007-3d-replay.md)). Сцена у вкладці «3D replay» на сторінці тесту реалістична: зі світінням, без ASCII-фактури, як «вікно в камеру згоряння». Виняток діє лише всередині рамки сцени. Усе навколо неї (кнопки, показники, шкала часу, підписи кадрів) робиться за правилами вище. Видима оболонка полум'я синя (`--flame`), UV-оболонка блідо-фіолетова (`#a99bf0`); вони завжди розрізняються ще й підписом. Реальні кадри камер поруч показуємо як є, так само як mp4.

## Графіки: одна тема

Усі графіки (d² і діаметри на сторінці тесту, превʼю й Порівняння, мапа Дослідника, таймлайн 3D) беруть одну тему з `frontend/src/shared/ui/chart/`:

| Що | Де | Правило |
|---|---|---|
| Кольори | `tokens.css` | виміри — `--ink` (растрові крапки 2 px), наша модель/оцінка — `--ink` пунктиром, подія і курсор — `--flame`, фінали — `--end-*`, додаткові серії — `--series-1`, `--series-2`, `--series-uv`; сітка — `--chart-grid`, шрифт осей — `--chart-font` (11 px Geist Mono) |
| Розміри | `theme.ts` | `MARGIN`, `DOT`, `GLYPH_R`; лінія 1.5 px |
| Фінали | `EndGlyph` | ● Extinction (заповнене коло), ○ Completion (кільце), ◇ Disruption (ромб) — ті самі, що в `EndMark`; колір ніколи не сам |
| Легенда | `ChartLegend` | HTML під графіком (підписи не обрізаються); пункти можуть бути перемикачами (`aria-pressed`) |
| Підказка | `ChartTooltip` | `--deep` + рамка `--rule`, моноширинний текст, список `dt/dd` |
| Прогалини | `TimeChart gaps` | діапазон без вимірів — пунктирна плашка `--deep` + пункт «no measurements» у легенді |

Приклад:

```tsx
<TimeChart
  series={[
    { id: "d2", label: "d² measured", points: d2 },                       // крапки
    { id: "fit", label: "linear fit (our estimate)", points: line, kind: "dashed" },
  ]}
  xLabel="time, s" yLabel="d², mm²" ariaLabel="…"
  markers={[{ x: burnTime, label: "flame out" }]}
  gaps={[[4.67, 6.0]]}
  legendExtra={[{ id: "gap", label: "no measurements", swatch: "band" }]}
/>
```

## Розбіжності, які треба пам'ятати

- **Мова.** Каркаси й DS написані українською, але UI робимо **лише англійською**, без перемикача (рішення 2026-11-15). Під час реалізації тексти перекладаємо.
- **Кольори фіналів.** У DS їх не було, тому додано токени `--end-*` (див. таблицю токенів): відтінки з каркасів, приглушені, завжди разом зі значком.
- **Нитка.** Пресети в каркасах рахують тести з ниткою і без разом. Це суперечить доменному правилу, тому при реалізації за замовчуванням рахуємо лише вільні краплі (`ts_fiber = No`).
