# StayHard frontend

Фронтенд — це `frontend/src` (React 19, Vite, TypeScript, react-router, TanStack Query). Вигляд
задає дизайн-система **StayHard**: темне поле, гострі кути, моноширинні кнопки в дужках, фактури
з ASCII-символів замість фото. Цей скіл — як не зламати ні вигляд, ні доменні правила, коли
додаєш щось нове.

## Джерела правди (читай у такому порядку)

1. `frontend/src/shared/styles/tokens.css` і `global.css` — що вже є в коді. **Бери звідси**,
   а не з HTML-макетів: у макетах свої класи й інлайн-стилі.
2. `docs/design/README.md` — дайджест DS, вибрані варіанти сторінок (1A · 2B · 3A · 4A · 5B),
   розбіжності макетів і коду.
3. `docs/design/layouts_flex.html` — каркаси сторінок (блоки A–H, L5, Q; дизайну там навмисно
   немає), `flex-landing.html` — лендінг, `stayhard-ds.html` — еталон DS. Це великі файли з
   вбудованими шрифтами: не читай їх цілком, шукай `grep`-ом потрібний варіант (`id="p1"` …).
4. `references/components.md` — що перевикористати (компоненти, класи, хуки, утиліти).
5. `references/textures.md` — якщо робиш canvas-анімацію чи «зображення».
6. `references/checklist.md` — перед тим, як казати «готово».

Тексти UI — **англійською**, документи в `docs/` — українською.

## Як будувати (порядок роботи)

1. **Знайди варіант у макеті** (`docs/design/README.md` → таблиця вибраних варіантів) і з'ясуй,
   які блоки (A–H, L5, Q) має сторінка. Блок без даних ховається, сітка не ламається.
2. **Подивись, що вже є.** Майже все базове зроблено: `.btn`, `.tag`, `.stat`, `.cells/.cell`,
   `.placeholder`, `EndMark`, `TimeChart`, `CopyButton`, `Placeholder`, `format.ts`. Новий
   примітив додавай у `shared/ui` лише якщо він потрібен двом фічам — інакше він живе у фічі.
3. **Дані — через API-хук фічі** (`features/<name>/api.ts`, TanStack Query), типи дзеркалять
   Pydantic-схеми бекенду. UI-ендпоінти — у `backend/src/flame/studies/flex/pages`
   (`/overview`, `/explorer`, `/tests/{n}/report`, `/replay`, `/library`); агентне API
   (`/tests?f=…`, `/compare`) — інший контракт, для UI його не тягни.
4. **Структура фічі:** `features/<name>/{api.ts,types.ts,content.ts,components/*.tsx,
   components/<name>.css,lib/*.ts,index.ts}`. Назовні — лише `index.ts`; інші фічі імпортують
   тільки його. Сторінка в `pages/` тонка (композиція), маршрут — у `app/router.tsx`.
   CSS-класи фічі мають власний префікс (`ov-`, `ex-`, `tp-`, `lib-`, `land-` …), щоб не
   перетиналися: у проді весь CSS склеюється в один файл.
5. **Чисті функції — у `lib/`, з тестом** `*.test.ts` поруч (`node:test`, див. checklist).
6. **Перевір у браузері** на десктопі й на 375 px (`references/checklist.md`).

## Візуальні правила і чому

- **Тільки токени.** Кольори — `var(--void|--deep|--line|--ash|--ink|--flame)`, фінали тестів —
  `var(--end-ext|--end-com|--end-dis)`. Сирий hex у компоненті = розсинхрон з DS при першій
  зміні палітри.
- **Синій `--flame` — лише «живе» або активне**: активний тег, курсор графіка, полум'я у фактурі,
  подія на графіку. Не фон, не великий блок, не кольори фіналів — інакше він перестає щось
  означати.
- **Кольори фіналів — завжди зі значком** (● Extinction, ○ Completion, ◇ Disruption) через
  `EndMark`. Зелений і червоний погано розрізняють дальтоніки; колір лише підсилює значок.
  Тільки для тексту, крапок і тонких ліній — без заливок.
- **Без заокруглень, тіней, градієнтів, неону.** `border-radius: 0` (у т.ч. для `input`,
  `button`), рамка — `var(--rule)` (1 px `--line`). Пунктир означає «неактивне / заглушка».
- **Кнопка — моноширинний текст у дужках** (`className="btn"`, дужки малює CSS). Головна дія
  одна на екран і біла; другорядні — `btn ghost`. Вимкнена — атрибут `disabled` (35 %).
- **Шрифти:** заголовки — `var(--display)` (IBM VGA, класи `.h-display`, `.h-section`), текст —
  `var(--sans)` (Geist), числа й гліфи — `var(--mono)` (Geist Mono, клас `.mono`). Атрибуція
  IBM VGA (CC BY-SA 4.0, VileR) у футері вже є — не прибирай її.
- **Показник** = велике тонке число + підпис попелом (`.stat > b + span`), число завжди з
  одиницею (мм, с, мм²/с, atm, %).
- **Графіки** — `shared/ui/chart/TimeChart` (SVG): виміри — растрові крапки, модель — тонка
  лінія, подія — синя мітка, підписи біля ліній замість легенди. Без бібліотек графіків.
- **Зображення = фактура.** Сирих фото й відео без фактури в макеті немає (виняток — mp4 NASA
  на сторінці тесту, це першоджерело). Одна велика фактура на екран; текст не кладемо на
  найяскравішу її частину. Як робити — `references/textures.md`.
- **Доступність:** ціль кліку ≥ 44 px (`var(--hit)`), фокус — `1px dashed var(--ink)` (уже в
  `global.css`), `aria-current` для активної навігації, `aria-pressed` для тумблерів-тегів,
  `role="status"` для повідомлень на кшталт «Copied», `prefers-reduced-motion` вимикає анімації.

## Доменні правила (порушення = неправда на екрані)

Це продукт про дані NASA; помилка тут гірша за криву верстку.

- **Кожне число на сторінці — з API.** Не пиши в JSX чи `content.ts` «274 tests», «61
  Disruption», «12 videos» — вони розійдуться з даними. У кураторських текстах (`content.ts`)
  номери тестів — це цитати («test #35»), не статистика.
- **Похідне підписуй `derived`** (тег `<span className="tag">derived</span>`): cool flame,
  «clean», схожі тести, `has_series`, теми публікацій. Наше обчислене (напр. фіт K) — «estimate».
- **Disruption = «self-extinction not observed»**, ніколи «would burn forever».
- **Тести з ниткою (`fiber`) не змішуємо з вільними краплями.** За замовчуванням показуємо
  вільні (`fiber=free`), решту — окремим рядком «Not counted: N on a fiber». У порівнянні
  змішування — з попередженням.
- **Чого ще немає — показуй `<Placeholder>`** («TODO (team): …», пунктирна рамка), а не
  вигаданий текст. Перед демо їх прибирають.
- **DOI FLEX видно і його можна скопіювати** (`CopyButton`); дані CC0, але DOI цитуємо.

## Чого уникати (бачили на практиці)

- **Горизонтальний скрол на телефоні.** Типові причини: `display:grid` без
  `grid-template-columns: minmax(0, 1fr)` (трек росте під широку таблицю), довгі DOI/URL без
  `overflow-wrap: anywhere`, фіксовані `min-width`. Таблиці — в обгортці з `overflow-x: auto`.
- **Шапка, що не влазить у 375 px.** Перевіряй вузьку ширину щоразу, коли додаєш щось у шапку.
- **Canvas, що розтягує картинку.** Буфер треба перевиділяти, коли змінилась *будь-яка* сторона
  (а не лише ширина) — див. `references/textures.md`.
- **Мертві якорі.** Сторінка, що вантажить дані, не має `#section` до завершення запиту — після
  завантаження прокрути до `location.hash` (див. `features/library`).
- **Імпорт у середину іншої фічі** (`@/features/x/components/Y`) — лише через `index.ts`.
- **Нова залежність заради дрібниці.** `npm install` на Windows псує `package-lock.json`
  (зникають поля `libc` → падає `npm ci` у Docker). Якщо залежність справді потрібна —
  оновлюй lockfile у Linux (`docker run --rm -v "$PWD":/app -w /app node:24 npm install`).

браузері на десктопі й 375 px без горизонтального скролу і помилок у консолі, числа — з API,
