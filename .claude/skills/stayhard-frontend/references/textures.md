# Фактури й canvas-анімації

У StayHard будь-яке «зображення» — це яскравість `f(x, y, t)` у діапазоні 0..1, відрендерена
символами ASCII-рампи `" .:-=+*#%@"` у клітинках ~9 px на `<canvas>`. Фото й ілюстрації напряму
не вставляємо. Готові приклади, з яких варто копіювати:

| Файл | Що показує |
|---|---|
| `features/replay/lib/ascii.ts` | мінімальний рендерер: сцена (крапля + сферичне полум'я) → символи; полум'я — `--flame`, решта — `--ink` |
| `features/replay/components/DropletReplay.tsx` | анімація з повзунком часу, пауза поза екраном, `prefers-reduced-motion` |
| `features/landing/lib/sky.ts` + `components/Sky.tsx` | Місяць, супутник, комети: великі сцени, «суцільні» клітинки, приглушення під текстом |
| `docs/design/stayhard-ds.html` (`lum()` / `render()`) | еталон DS; читай через `grep`, файл великий |

## Правила (і чому)

1. **Палітра — з CSS-змінних**, прочитаних через `getComputedStyle(el)` (`--void`, `--ink`,
   `--flame`, `--mono`). Тоді фактура змінює колір разом з токенами.
2. **Буфер canvas = CSS-розмір × devicePixelRatio (≤ 2)** і перевиділяється, коли змінилась
   **будь-яка** сторона:
   ```ts
   const bw = Math.round(W * dpr), bh = Math.round(H * dpr);
   if (cv.width !== bw || cv.height !== bh) { cv.width = bw; cv.height = bh; }
   g.setTransform(dpr, 0, 0, dpr, 0, 0);
   ```
   Якщо порівнювати лише ширину, то при зміні `aspect-ratio` (напр. 21:8 на десктопі і 4:3 на
   телефоні) старий буфер розтягується і сфера стає еліпсом.
3. **Нормалізовані координати від висоти кадру** (центр 0,0; висота = 1), щоб сцена не
   деформувалась на будь-якому співвідношенні сторін.
4. **≈ 11 кадрів/с** (`FRAME_MS ≈ 90`) — це частина стилю (ретро-растр), а заразом дешево для CPU.
5. **Пауза поза екраном** (`IntersectionObserver`) і **один статичний кадр** при
   `prefers-reduced-motion: reduce`.
6. **Перемальовування на resize** (`ResizeObserver` на canvas) і після `document.fonts.ready`
   (інакше перший кадр малюється запасним шрифтом).
7. **Прибирання в `useEffect` cleanup:** `cancelAnimationFrame`, `disconnect()` обсерверів,
   `removeEventListener`; прапорець `alive` для промісів (`fonts.ready`).
8. **Текст не на найяскравішій частині:** або розміщуй сцену поруч із текстом, або приглушуй
   символи під блоком тексту (див. `dim` у `drawSky`).
9. **Одна фактура в одному зображенні**, одне велике зображення-фактура на екран.
10. **Доступність:** `role="img"` + змістовний `aria-label` для інформативного canvas
    («Test 35: droplet and flame drawn from measured diameters»), `aria-hidden="true"` для
    декоративного (комети).
11. **Чесність даних:** якщо фактура показує виміри (replay), підпиши це («Animation from measured
    diameters · test #35») і бери розміри з API, а не «на око».
